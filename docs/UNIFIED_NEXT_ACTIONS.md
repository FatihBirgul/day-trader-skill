This delivery is not completion of the full unified-engine mission. Public V5 orchestration and real local private descriptive reuse work; complete private Forex strategy integration does not.

1. Select an authorized writable private integration target. No new repository or visibility change was made. The local restricted bridge and detailed inventory must not be pasted into the public PR. A new private repository requires the user's approval; an existing authorized private target can be used under its own rules.
2. Resolve market/contract/calendar/volume eligibility: real broker CFD versus spot identity, authoritative session/DST/holiday gaps, and per-method OHLC capability contracts. Do not remove real-volume gates or pretend the original four crypto strategies support Forex. Changes belong in an approved private integration workspace, while trade-ai remains read-only for this task.
3. Finish missing/partial candle/chart families, per-family independent positive/negative and knowledge/invalidation fixtures, support/resistance zones, equal levels and calibrated regime eligibility. Keep OHLC heuristics descriptive; do not invent institutional order data.
4. Connect the existing private train/select/freeze/test research to verified Forex data and broker cost/rule archives without rewriting its completed continuation work. Add genuine point-in-time source/license evidence, stable parameter versions and appropriate purge/embargo. Public fixed-rule rolling evaluation remains separately named.
5. Verify a Windows MT5 demo terminal through read-only diagnostics: symbol mapping, contract/tick/point/currency/grid, permitted directions, session/quote freshness and broker profit. No order placement is needed or authorized. Margin/leverage/swap remain unavailable unless independently verified.
6. Select permitted, reliable macro/news/calendar sources and capture point-in-time source/coverage/freshness. The new declared-source contract is not a protective event filter. Connect V5 scanner/alert consumers only after their new status/null/integration handling is reviewed.
7. Keep hosting/auth/HTTPS/PWA/Windows UI separate. A powered-off MT5 PC cannot supply live prices.

Public follow-up and deployment packaging: best case 2-4 engineer-days; broker/calendar/CFD and private capability work: 4-8 days; remaining pattern/strategy validation: 5-12 days; Forex OOS/provenance/cost integration: 5-12 days; Windows read-only pilot and macro adapters: 3-7 days. Some can overlap. Best-case focused continuation about 2-3 engineer-weeks, realistic 4-8 weeks for one engineer, excluding waiting for permissions/data access and forward-market observation. These estimates are unverified assumptions based on this code audit. Market edge, source licensing, broker variants and reliable calendars are the largest uncertainties; no development estimate guarantees profitability.
