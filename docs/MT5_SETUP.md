# Windows MT5 kurulumu

Windows'ta MetaTrader 5 terminalini kurup demo hesabında oturum açın. Python 3.10+ ve terminal ile aynı kullanıcı oturumunda `pip install -r requirements-api.txt MetaTrader5` çalıştırın. Gerçek hesap şifresini depoya veya `.env` dosyasına yazmayın. Brokerın XAUUSD adını MT5 Market Watch'ta doğrulayın; suffix veya prefix varsa `MT5_SYMBOL_MAP` ortam değişkenine `{"XAUUSD":"XAUUSD.r"}` biçiminde JSON eşleme verin veya `MT5Provider(mappings={'XAUUSD':'XAUUSD.r'})` kullanın. `symbol_info`, `symbol_info_tick`, `copy_rates_from_pos` ve `order_calc_profit` sonuçlarını demo terminalde kontrol edin. Backend `uvicorn forex.api:app --host 127.0.0.1 --port 8000` ile yerel açılır. Varsayılan provider MT5'tir. Linux Cloud ortamında gerçek terminal testi yapılmadı.

V2 doğrulaması: `GET /api/v1/health` terminalin bağlı olduğunu denetler. Terminal kapalıysa HTTP 503 beklenir. `MT5_SYMBOL_MAP` eşlemesi brokerın Market Watch listesindeki tam ada karşılık gelmelidir; örnek yalnızca biçimi gösterir. Gerçek demo hesapta XAUUSD, EURUSD ve USDJPY için tick değeri, hesap para birimi, minimum lot, lot adımı, işlem izni ve `order_calc_profit` zarar işareti ayrıca kontrol edilmelidir. Cloud testleri bu gerçek bağlantıyı kapsamaz.

V3: canlı BUY/SELL planı için brokerın doğrulanmış saatlerini `MT5_BROKER_HOURS` ile açıkça tanımlayın. Format ve sınırlar `docs/SESSION_ENGINE.md` içindedir. Yapılandırılmamış broker saatleri `UNKNOWN` kabul edilir.
