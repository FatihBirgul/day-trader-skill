Inspected source families: technical/analysis/MTF/confluence; candle/chart patterns; liquidity/order flow/futures/liquidation/outcome; market data/QC/capabilities; technical adapter/price action/regime/strategies/router/pipeline; scanner/paper risk/analysis service/immutable decisions; continuation pattern/chart/research/history/profiles/walk-forward/validation. Exact private paths/functions and technical details remain in the restricted inventory, rather than being published here.

Real isolated integration exercised the data contract/QC/capabilities, regime, price action, technical research, candle/chart research and confluence components against explicit synthetic gold-spot metadata. The aggregate real-volume technical adapter refused tick-volume input; the FX strategy pipeline refused unavailable calendar eligibility. CFD was not relabelled spot. Product/scanner/ledger/paper-risk integration was deliberately excluded because it has market, storage and/or execution assumptions incompatible with this read-only Forex host.

Three selected preserved private development refs were compared with the continuation snapshot locally; protected refs and backups were unchanged. Full formula-by-formula mathematical validation of every private module and every pattern family is not claimed. Source presence, passing original tests, actual bridge execution and live-market validation are separate evidence levels.
